# FIGURAMASTER — Android, тестовая ветка

Первый прототип приложения отображает онлайн-атлас https://figuramaster1966-coder.github.io/music/ в WebView.

- Ветка `figura-android-preview` используется только для тестовой сборки APK.
- Основной сайт и ветка `main` не затронуты.
- Иконка в этой версии **временная**: перед выпуском будет заменена по выбору владельца.
- GitHub Actions собирает **отладочный** `app-debug.apk`, который можно вручную установить для тестирования.
- Интерфейс и музыка загружаются через интернет, изменения на сайте будут отображаться при перезапуске приложения.
- Отладочная версия не предназначена для публикации в Google Play.

Получение файла: GitHub → Actions → Build FIGURAMASTER Android APK → последний успешный запуск → Artifacts → FIGURAMASTER-Android-debug-APK.
